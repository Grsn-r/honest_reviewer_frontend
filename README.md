# Honest Reviewer

A full-stack social platform where users can share reviews, interact with content, and manage their profiles securely.

**Author:** Gerson Ruíz Sequeda

## Live Demo

🔗 https://honest-reviewer.vercel.app/

## Features

### Authentication & Security

* User registration with duplicate email validation.
* Secure login system.
* JWT-based authentication.
* Protected routes accessible only to authenticated users.
* Password change requires verification.

### User Profile

* Update profile information.
* Change account password securely.

### Content Management

* Create and publish posts.
* Upload images.
* Comment on posts.
* React to content.
* Users can delete their own posts and comments.
* Users cannot modify or delete content created by others.

### Responsive Design

* Mobile-friendly interface.
* Optimized for tablets.
* Responsive layout for desktop devices.

## Project Highlights

* Full authentication flow with route protection.
* User authorization and ownership validation.
* Image upload functionality.
* Responsive user interface.
* RESTful API integration.
